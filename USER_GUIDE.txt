PL Mapping Viewer 0.3.1
Creator: Hwi Je Woo
Updated: 2026-09-11

START
Extract the entire OS-specific ZIP. macOS: double-click Launch PL Mapping Viewer.command.
Windows: run PL-Mapping-Viewer.exe. Keep the terminal open; Ctrl+C stops the app.
Normal processing is local/offline. The browser address is printed in the terminal.

IMPORT
Use Open Data File, choose a file, confirm grid width and height, then Apply and Open.
Supported: DataFrame pickle, numeric NumPy NPY/NPZ, and CSV/TXT/TSV/DAT/ASC tables.
Pickle is a Python executable serialization format: open only files from trusted sources.
NPY/NPZ object arrays are rejected. NPZ can contain data, wavelengths, width, height.
The canonical matrix has spectral channels in rows and pixels in columns.
Pixels are row-major: index = y * width + x, x increases right, y increases down.
Raw arrays use heuristics to infer axis order; confirm dimensions and known pixel spectra.
Numeric spectral axes are interpreted as wavelength in nm in this release. Convert energy
or wavenumber axes before import. Spectral axes must be finite and strictly monotonic.
Non-numeric axes use channel indices. Non-square maps require explicit or embedded dimensions.
Reload source explicitly rereads a selected source and clears selected traces.

MAP AND SPECTRA
Click a mean spectrum wavelength or drag a wavelength range. The map can show a single
channel, the unweighted sum of channels, or their mean. Range Sum is NOT a wavelength
integral; unequal wavelength spacing is not weighted. Numeric range controls also apply.
Click the image in Point mode to select a spectrum. Line mode extracts each pixel along
the line, averaging a perpendicular band according to Line Thickness. All line samples
are retained (the former 96-sample limit is removed). Space calibration uses scan extent
between first and last pixel centers: step = scan size / (pixel count - 1).
The map preview is at most 256 pixels on its longest edge. Clicking selects the original
pixel represented by that displayed nearest-neighbor sample. Use full CSV export for all pixels.
Scan calibration is user-entered and is not an automatic instrument calibration.

MISSING DATA AND PROCESSING
Non-finite values remain missing: gray map pixels, gaps in curves, empty CSV cells.
Averages and sums ignore missing samples, but all-missing groups remain missing.
Clicked-trace processing order: reference division, channel-index polynomial smoothing,
then optional min-max normalization. A reference denominator with magnitude below 1e-12,
or a missing reference, produces a missing result rather than an amplified artificial value.
Smoothing does not fill originally missing samples and assumes channel-index spacing.
Trace Offset affects display only; exported clicked-trace values exclude this offset.
Auto contrast ignores missing values. Actual Min/Max values set manual color limits;
Auto contrast restores automatic limits. Reference division and normalization are not
background subtraction or detector-response calibration.

EXPORT
Map CSV downloads a ZIP with full-resolution image.csv and metadata.json. CSV columns:
x_pixel, y_pixel, intensity. Metadata records source identity, axis, selection, mode,
import settings, units, missing policy and app version. This is the complete selected map,
not just the visible preview. Reopen the source if it changed after the preview was rendered.
Clicked CSV exports processed spectra without visual offsets. Its first line is a '# '
JSON metadata comment; use comment='#' when reading with pandas. It records processing
settings and line/point selections. Line CSV also has coordinate and distance rows.
Mean CSV exports the RAW global mean, even if the mean plot has reference division enabled.
PNG and Copy capture rendered appearance; map PNG remains a preview image without a full
scientific figure frame. Use full CSV for quantitative analysis and final figure preparation.
Multi stores rendered image snapshots, not independent raw datasets.

SESSION
The most recent session is automatically saved to the OS app-data directory alongside
retained uploaded copies. Save session also downloads JSON; Open session JSON reloads it.
Point and averaged line spectra, group IDs, line thickness, distances and settings are kept.
Reopen sessions on the same computer while the original/uploaded source is available.
A changed source identity prevents old trace snapshots from being restored onto new data.
Session JSON is not a portable raw-data archive. Browser legacy sessions can restore points,
but cannot reconstruct line metadata that old versions never saved.

LIMITS
ROI polygons, background subtraction, peak fitting/maps, batch workflows and physical-axis
conversion are planned separately. Bright PL patterns alone do not establish a mechanism.
Keep original measurements and processing conditions with research conclusions.
For errors, retain the version, source format, grid, exact steps and console/log output.

UPDATE NOTIFICATIONS
Check for updates queries the public GitHub repository. Check once daily is enabled by
default and can be disabled. Include preview releases is enabled for this preview build;
uncheck it for stable releases only. Preferences are per browser origin, separate from
analysis sessions. Successful checks are cached on disk for 24 hours. Manual checks bypass
that cache except a 15-second request throttle. Failed checks retry after 5 minutes.
The lookup has a short timeout and never blocks local analysis. No measurement data is sent.
Open releases opens GitHub only after you click. Choose the ZIP for your OS, quit the old
app, extract the new package and relaunch. User data stays outside the package. No automatic
download or installer is included. v0.3.0 users must manually install v0.3.1 once to gain
these notifications.

0.4.0 축 단위 및 패널 조절
- 파일 열기는 맨 위, 테마/업데이트 확인은 맨 아래에 있습니다.
- Spectrum axis에서 nm/eV/Raman shift/wavenumber 선택 후 Apply axis units를 누르세요.
- Raman shift는 실제 여기 레이저 파장(nm)을 입력해야 합니다.
- 원본 수치 축은 nm로 해석합니다. 채널 번호만 있는 파일은 먼저 파장 보정이 필요합니다.
- 강도는 측정 채널당 값을 유지하며 스펙트럼 밀도 변환은 하지 않습니다.
- 이미지 폭 비율과 높이 입력 또는 이미지 프레임 아래쪽 조절점으로 크기를 변경합니다.
- 테마 변경 시 그래프 기본 색상과 배경이 함께 바뀌며 이후 개별 조절도 가능합니다.
