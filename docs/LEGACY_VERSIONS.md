# Legacy snapshots

The public repository retains historical `win_version0.1/` and `backups/` content.
A local `win_version0.2/` snapshot was preserved during development but is not a
required part of this source publication. None of these folders is a current build input.

For v0.3.1 use the root `build_windows_binary.bat` and `scripts/build_binary.py`.
The shared root Python modules and `pl_mapping_static/` are canonical on both platforms.
Do not copy current edits into historical snapshots.
